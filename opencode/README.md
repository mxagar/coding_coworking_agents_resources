# OpenCode

[OpenCode](https://opencode.ai) is an **open-source** AI coding agent with a terminal interface, desktop app, and IDE extension. Unlike Claude Code (Anthropic-only), OpenCode supports 75+ LLM providers.

Official documentation: [opencode.ai/docs](https://opencode.ai/docs)

## 1. Getting Started

### Installation

```bash
# One-liner (Mac/Linux)
curl -fsSL https://opencode.ai/install | bash

# Package managers
npm install -g opencode-ai
bun install -g opencode-ai
brew install sst/tap/opencode     # macOS

# Windows
scoop install opencode            # recommended
# or use WSL
```

### Starting a Session

```bash
cd /path/to/my/project
opencode           # open TUI
/connect           # add LLM provider credentials
/models            # select preferred model
/init              # generate AGENTS.md (equivalent to CLAUDE.md)
```

### Commands & Keybindings

Built-in slash commands:

```
/init      Generate AGENTS.md for the project
/connect   Add/update LLM provider credentials
/models    Select active model
/undo      Reverse last changes
/redo      Reapply undone changes
/share     Create a public shareable link
/unshare   Remove the public link
/help      Show help
```

Keybindings use a **leader key** (default: `Ctrl+X`):

| Keybind | Action |
|---|---|
| `Tab` | Cycle between Build / Plan agents |
| `<leader>n` | New session |
| `<leader>l` | Session list |
| `<leader>g` | Session timeline |
| `<leader>x` | Export session |
| `<leader>a` | Switch agent |
| `<leader>m` | Switch model |
| `<leader>y` | Copy last message |
| `<leader>u` / `<leader>r` | Undo / Redo |
| `<leader>b` | Toggle sidebar |
| `Ctrl+C` | Clear input |
| `Shift+Enter` | New line in input |

Keybindings are customized in `tui.json`; set to `"none"` to disable.

## 2. Configuration

### Config File Hierarchy

Later entries override earlier ones:

1. Remote config (`.well-known/opencode` in repo)
2. Global config (`~/.config/opencode/opencode.json`)
3. `OPENCODE_CONFIG` environment variable (path to config file)
4. Project config (`opencode.json` in project root)
5. `OPENCODE_CONFIG_CONTENT` env var (inline JSON)

Format: JSON or JSONC (comments allowed).

### Key Config Sections

```jsonc
{
  "model": "anthropic/claude-sonnet-4-5",   // default model
  "small_model": "openai/gpt-4o-mini",       // lightweight tasks
  "provider": { /* provider-specific options */ },
  "agent": { /* custom agent definitions */ },
  "command": { /* custom commands */ },
  "permission": { /* tool access rules */ },
  "mcp": { /* MCP server definitions */ },
  "tools": { /* enable/disable specific tools */ },
  "share": "manual",                          // manual | auto | disabled
  "snapshot": true                            // change tracking (default: true)
}
```

Variable substitution in config values:
- `{env:VARIABLE_NAME}` — inject environment variable
- `{file:path/to/file}` — inject file contents

### AGENTS.md

Equivalent to `CLAUDE.md`. Generated by `/init`, it documents project structure and coding conventions and is loaded automatically each session.

Custom agents can also reference a prompt file via `opencode.json`.

## 3. Providers & Models

OpenCode supports 75+ providers. Notable ones:

| Provider | Notes |
|---|---|
| OpenCode Zen | Recommended for newcomers; subscription-based |
| OpenCode Go | Low-cost subscription |
| GitHub Copilot | Uses existing Copilot subscription |
| Amazon Bedrock | Supports VPC endpoints |
| Google Vertex AI | Enterprise Google Cloud |
| Azure OpenAI | Enterprise Azure |
| Ollama / LM Studio | Local/open-source models |
| Anthropic | Direct API key |
| OpenAI | Direct API key |

Model config syntax:

```jsonc
{
  "model": "provider_id/model_id"
  // e.g. "anthropic/claude-sonnet-4-5"
  //      "openai/gpt-4o"
  //      "ollama/llama3"
}
```

Model selection priority: CLI flag → config file → last used → default.

## 4. Tools Available to AI

**Built-in tools:**

| Category | Tools |
|---|---|
| File ops | `read`, `write`, `edit`, `patch` |
| Search | `grep`, `glob`, `list` |
| Execution | `bash` |
| Web | `webfetch`, `websearch` (Exa AI — requires `OPENCODE_ENABLE_EXA=1`) |
| Dev | `lsp` (experimental — definitions, references), `skill`, `todowrite`, `question` |

**Custom tools** — TypeScript or JavaScript files in `.opencode/tools/` (project) or `~/.config/opencode/tools/` (global). The filename becomes the tool name. Can override built-in tools by name.

```typescript
// .opencode/tools/my-tool.ts
import { tool } from "opencode/tool";
import { z } from "zod";

export default tool({
  description: "My custom tool",
  parameters: z.object({ input: z.string() }),
  execute: async ({ input }) => { return { result: input }; },
});
```

## 5. Agents & Plan Mode

### Built-in Agents

OpenCode has two primary agents switched via `Tab`:

| Agent | Description | Restrictions |
|---|---|---|
| **Build** | Default; full tool access for development | None |
| **Plan** | Analysis/planning only, no changes | `edit: deny`, `bash: deny` |

This is the equivalent of Claude Code's plan mode — switch to the **Plan** agent to analyze before implementing, then switch back to **Build** to execute.

Built-in subagents (invoked automatically or via `@mention`):

- **General** — multi-step tasks with full tool access
- **Explore** — fast, read-only codebase exploration

### Custom Agents

Create a markdown file with frontmatter:

```bash
# Project-level
.opencode/agents/MyAgent.md

# Global
~/.config/opencode/agents/MyAgent.md
```

```markdown
---
name: MyAgent
description: Does X. Use when Y.
model: anthropic/claude-sonnet-4-5
mode: subagent          # primary | subagent | all
temperature: 0.3
max_steps: 20
permission:
  edit: ask
  bash: deny
---

You are a specialized agent that...
```

## 6. Skills

Skills work the same way as in Claude Code — lazy-loaded instruction sets. OpenCode also reads Claude-compatible paths, so **existing `.claude/skills/` work as-is**.

Lookup order:

```
.opencode/skills/<name>/SKILL.md     (project)
~/.config/opencode/skills/<name>/SKILL.md  (global)
.claude/skills/<name>/SKILL.md       (Claude-compatible, project)
~/.claude/skills/<name>/SKILL.md     (Claude-compatible, global)
```

`SKILL.md` frontmatter requires `name` and `description`. Permission control per skill in `opencode.json`:

```jsonc
{
  "permission": {
    "skill:my-skill-name": "allow"   // allow | deny | ask
  }
}
```

## 7. MCP Servers

Same concept as Claude Code. Configure in `opencode.json`:

```jsonc
{
  "mcp": {
    "context7": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "@upstash/context7-mcp"]
    }
  }
}
```

## 8. Custom Commands

Equivalent to Claude Code skills but invoked explicitly as slash commands. Two ways to define:

**Markdown file** in `.opencode/commands/` (project) or `~/.config/opencode/commands/` (global):

```markdown
---
name: code-review
description: Review code for issues
agent: build
---

Perform a thorough code review focusing on: $ARGUMENTS

Review the files changed since the last commit.
```

**Inline in `opencode.json`:**

```jsonc
{
  "command": {
    "code-review": {
      "description": "Review code for issues",
      "template": "Perform a code review focusing on: $ARGUMENTS"
    }
  }
}
```

Supported template features:
- `$ARGUMENTS` or `$1`, `$2`, `$3` — positional arguments
- `` !`git diff HEAD` `` — inject bash command output
- `@filename` — inject file contents

Invoke as: `/code-review BUGS,SECURITY`

## 9. Permissions

Granular per-tool control in `opencode.json` (or per-agent):

```jsonc
{
  "permission": {
    "bash": "ask",         // ask before every bash command
    "write": "allow",      // always allow file writes
    "webfetch": "deny",    // never allow web fetches
    "bash:rm *": "deny"    // pattern-match specific commands
  }
}
```

Values: `allow`, `deny`, `ask`. Supports `*` and `?` wildcards.

Defaults: most tools `allow`; `doom_loop` and `external_directory` default to `ask`; `.env` file reads default to `deny`.

## 10. Sharing

```bash
/share     # creates public link: opncd.ai/s/<id>
/unshare   # removes public access and deletes data
```

Config modes (in `opencode.json`):

```jsonc
{
  "share": "manual"    // manual (default) | auto | disabled
}
```

- `manual` — generate links on demand
- `auto` — automatically share all new conversations
- `disabled` — prevent all sharing (compliance/enterprise)

Note: conversation history is uploaded to OpenCode servers when shared. Avoid sharing sessions with proprietary or confidential code.

## 11. Claude Code vs OpenCode — Equivalency Table

| Feature | Claude Code | OpenCode |
|---|---|---|
| **Open source** | No | Yes |
| **LLM providers** | Anthropic only | 75+ providers |
| **Local models** | No | Yes (Ollama, LM Studio, llama.cpp) |
| **Config file (project)** | `.claude/settings.json` | `opencode.json` |
| **Config file (global)** | `~/.claude/settings.json` | `~/.config/opencode/opencode.json` |
| **Project instructions** | `CLAUDE.md` | `AGENTS.md` |
| **Init command** | `/init` | `/init` |
| **Plan mode** | `/plan` or `Shift+Tab` | `Tab` (switches to Plan agent) |
| **Custom agents** | `.claude/agents/<name>.md` | `.opencode/agents/<name>.md` |
| **Built-in subagents** | Explore, Plan, general-purpose | General, Explore |
| **Skills** | `.claude/skills/<name>/SKILL.md` | `.opencode/skills/` (+ reads `.claude/skills/`) |
| **MCP servers** | `claude mcp add` / `settings.json` | `opencode.json` `mcp` section |
| **Custom commands** | Skills (slash commands) | `.opencode/commands/<name>.md` |
| **Hooks** | `hooks` in `settings.json` (PreToolUse, PostToolUse, …) | No dedicated hooks; use custom tools/commands |
| **Web search** | Built-in | Exa AI (`OPENCODE_ENABLE_EXA=1`) |
| **Permissions (interactive)** | `Shift+Tab`, yes/don't ask again | `permission` per tool/agent in config |
| **Skip all permissions** | `--dangerously-skip-permissions` | `permission: { "*": "allow" }` in config |
| **Undo changes** | `ESC×2` or `/rewind` | `/undo`, `/redo` |
| **Auto-memory** | `~/.claude/projects/.../memory/MEMORY.md` | No equivalent (sessions + snapshots) |
| **Sharing conversations** | Not built-in | `/share` → `opncd.ai/s/<id>` |
| **Cloud execution** | `claude.ai/code` cloud environments | Not available |
| **Scheduling tasks** | `/schedule`, `CronCreate` tool | Not available |
| **Custom tools** | Not supported | TypeScript/JS in `.opencode/tools/` |
| **LSP integration** | IDE extension | Built-in `lsp` tool (experimental) |
